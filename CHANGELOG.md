# Changelog

## v0.2.0 — 2026-11-08

- Combine the measured lab service, empirical simulator and web demo without
  changing the frozen model parameters.
- Add English installation, API, experiment, data and reproducibility guides,
  MIT licensing, citation metadata, CI and publication checks.
- Retain semantic, broadcast and random sequential search and a consolidated
  single-database comparison. Random sequential changes order, not placement.
- Preserve five figures, including the 2026-10-23 distinct line markers and the
  0.0–1.0 threshold replay grid.
- Publish a checksummed input archive. Replace only local `source_csv` paths with
  basenames; preserve numeric observations.
- Add a portable dataset fetcher and parameterized runner for future measurements.
  This release adds no new physical experiment or validation of unseen scales.

The bundle release is v0.2.0. Archived lab runtime metadata remains v0.1.0;
simulator interface metadata is v0.3.0 and its calibrated model is v0.1.0.
